## ДИАГНОЗ

- UoM: в МойСклад API `uom` у товара — это только meta-ссылка (`{"meta":{"href":.../entity/uom/<uuid>}}`),
  поля `name` в ней нет, поэтому `product.obj("uom")?.str("name")` всегда давал null → строка без единиц.
  Решение: справочник `entity/uom` (limit 100) один раз за сессию, кэш в репозитории; имя берём из
  раскрытого `uom.name`, иначе по id из href через справочник.
- Оприходование: тип документа в API — `enter` (Оприходование), `supply` — это Приёмка.
- Дополнительно: `expand=store` может не поддерживаться у enter/loss → фолбэк на запрос без expand
  и дочитывание имени склада через `entity/store/{id}`.

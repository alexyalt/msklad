# msklad

Android-приложение (Kotlin) для наполнения готового документа «Перемещение» в МойСклад: сканирование или ручной ввод кодов товаров, добавление позиций в документ и показ остатков на складе-источнике и складе-получателе.

Техническое задание: `docs/TZ.md`. Правила для агента: `AGENTS.md`. Журнал работ: `WORKBOOK.md`.

## Как пользоваться

1. Создайте документ «Перемещение» в веб-интерфейсе МойСклад (с указанием складов).
2. В приложении на экране настроек введите логин, пароль и номер или ID (UUID) перемещения, нажмите «Начать».
3. На главном экране сканируйте штрихкод камерой или введите код вручную, при необходимости укажите количество и нажмите «Отправить».
4. Зелёная зона результата и короткий звук — успех, красная и долгий низкий звук — ошибка.

## Сборка

Нужны JDK 17 и Android SDK 34.

```
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. В GitHub Actions (workflow `Android CI`) APK публикуется как артефакт `msklad-debug-apk`.

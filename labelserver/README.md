# Сервер печати этикеток для Windows

Формирует PDF этикеток в МойСклад и отправляет его на принтер этикеток через SumatraPDF. Запросы приходят от Android-приложения по локальной сети или Tailscale.

## Что нужно на компьютере

1. Python 3.10 или новее (python.org, при установке включите «Add Python to PATH»).
2. SumatraPDF (sumatrapdfreader.org), запомните путь к `SumatraPDF.exe`.
3. Принтер этикеток Godex, установленный в Windows как принтер. В свойствах принтера задайте размер бумаги этикетки (для шаблона «Термоэтикетка (58х40мм)» — 58×40 мм) и точку по умолчанию.
4. Tailscale, если планируете печатать с телефона вне дома. IP компьютера в Tailscale смотрите в приложении Tailscale или командой `tailscale ip -4`.

## Установка

1. Скопируйте папку `labelserver` на компьютер.
2. Скопируйте `config.example.ini` в `config.ini` и заполните:

```ini
[server]
login = admin@company          # логин МойСклад
password = пароль              # пароль МойСклад
printer = GODEX G500           # имя принтера: ровно как в «Устройства и принтеры»
sumatra_path = C:\Program Files\SumatraPDF\SumatraPDF.exe
template = Термоэтикетка (58х40мм)   # имя шаблона из МойСклад, можно с латинской x
host = 0.0.0.0
port = 5000
print_settings = fit           # ключ -print-settings для SumatraPDF: fit, noscale, paper=58x40mm
max_count = 500
```

`config.ini` в репозиторий не попадает: он в `.gitignore`, потому что содержит пароль.

3. Запустите `run.cmd`. При первом запуске создаётся виртуальное окружение и ставятся зависимости, потом запускается сервер. Окно консоли должно остаться открытым.

Проверка: откройте в браузере `http://127.0.0.1:5000/health` — должно вернуться `{"ok": true, "printer": "..."}`.

## Как подключить телефон

В приложении откройте «Настройки», в поле «IP компьютера для этикеток» введите адрес компьютера и при необходимости порт: `100.101.102.103` или `100.101.102.103:5000`. Если поле пустое, кнопка «ЭТИК» в приложении не показывается.

Windows может спросить разрешение для брандмауэра при первом запуске — разрешите доступ в частных и общедоступных сетях, иначе телефон не достучится.

## API сервера

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/health` | проверка, что сервер работает |
| POST | `/print` | печать этикеток |

Тело запроса на печать: `{"code": "00001", "count": 3}`. `code` — код, штрихкод или артикул товара, `count` — целое число от 1 до `max_count`.

Ответ при успехе: `{"ok": true, "name": "Товар 1", "code": "00001", "printed": 3}`. При ошибке — JSON `{"error": "текст"}`, код HTTP 400 (неверные данные), 404 (товар не найден), 500 (ошибка печати или настройки), 502 (ошибка МойСклад).

В папке `pdf` остаются напечатанные файлы за последние сутки — на случай, если принтер не сработал.

## Если не печатает

- **`Не найден SumatraPDF`** — проверьте `sumatra_path`, путь с пробелами указывается без кавычек.
- **`SumatraPDF завершился с ошибкой`** — чаще всего неверное имя `printer`. Имя должно точно совпадать со списком принтеров в Windows.
- **`Не найдено: шаблон этикетки`** — в ответе перечислены доступные шаблоны из МойСклад, скопируйте нужный в `config.ini`.
- **`Нет связи с МойСклад`** — проверьте интернет и логин с паролем.
- **Телефон не подключается** — проверьте, что сервер запущен, Tailscale включён на телефоне и на компьютере, а брандмауэр не блокирует порт.
- **Печатает не тот размер или обрезает** — задайте размер бумаги в драйвере принтера и попробуйте `print_settings = noscale` вместо `fit`.

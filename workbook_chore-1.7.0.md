# WORKBOOK ветки `chore/1.7.0`

Итерация: ревизия репозитория и релиз **1.7.0**. Нового функционала не вносим — пользователя
устраивает текущее поведение приложения. Задача: найти ошибки и артефакты разработки, исправить,
выпустить версию.

  которая уже влита в `main` (`git rev-list --count origin/main..origin/fix/offline-positive-stock` = 0).
  Незавершённых веток нет → создана рабочая ветка `chore/1.7.0` от `main`.
- Теги: `v1.5`, `v1.5.1`, `v1.5.2`, `v1.5.3`, `v1.6.0`, `v1.6.1`, служебный `latest`.
- Прочитаны `ARCHITECTURE.md`, `WORKBOOK.md`, `AGENTS.md`, `README.md`, `docs/TZ.md`, затем код
  по карте модулей (3097 строк Kotlin, 19 файлов).

## Что проверено

1. **Секреты в репозитории.** Grep по `manubad`, `ghp_`, `password`, `пароль`: тестовых учёток и токенов
   в файлах нет (в `labelserver/config.example.ini` — заглушка, `config.ini` в `.gitignore`).
   Токен GitHub при клонировании не остался в `.git/config` (remote переписан на чистый URL,
   авторизация — через заголовок на один вызов).
2. **Сборка/CI.** `.github/workflows/android-ci.yml` валиден (YAML парсится), JDK 17, `assembleDebug`,
   артефакт `msklad-debug-apk`, публикация в `latest` при push в `main`. Не менялся.
3. **Строковые ресурсы.** 102 строки, из них две не используются ни в коде, ни в разметке:
   `product_line`, `offline_loaded_at` (наследие 1.5.x).
4. **Мёртвый код.** `DocumentRepository.undoAdd` (остался от кнопки «✕» в зоне результата, удалённой
   в 1.5.3; ни одного вызова), неиспользуемое поле `SettingsActivity.busy`,
   недостижимая ветка `strict = true` в `SettingsViewModel.resolveExtra` (единственный вызов —
   `strict = false`, т.е. поведение не меняется).
5. **Импорты.** Неиспользуемых импортов нет; `Log.*` только по делу (`SoundPlayer`, `labelserver`).
6. **Строки интерфейса.** Русский текст в разметке не захардкожен (кроме символа «✕» в
   `item_recent_scan.xml` — это глиф, а не текст, оставлен осознанно).
7. **API-слой.** Проверено живым запросом к тестовому аккаунту: `ApiFactory` отправляет
   `Accept: application/json;charset=utf-8` и `Accept-Encoding: gzip` — именно этого требует МойСклад
   (без них ответ 400/415, код ошибки 1062). Логика репозитория соответствует знаниям по API
   из `WORKBOOK.md` (фильтр `id` только UUID, `store=<href>`, явный `qty > 0`).
8. **Документация.** `README.md` описывал офлайн-режим по состоянию 1.5.x: кнопка «Офлайн Синхронизация»
   на экране настроек (убрана в 1.6.0), фильтр внешних штрихкодов «с сообщением» (с 1.5.2 — молча).
   Расхождение с фактическим поведением → исправлено.
9. **Логика.** Ревизия `DocumentRepository`, `MainViewModel`, `MainActivity`, `OfflineModels`,
   `ScanJournal`, `OfflineStore`, `LabelViewModel`, `SettingsViewModel` — функциональных ошибок,
   требующих правки, не найдено. Спорные, но корректные места (не менялись):
   `removeQuantity` уменьшает остаток вычитания на всю позицию (работает, т.к. при `rest > 0`
   остаток становится отрицательным и цикл останавливается), `OfflineStore.load()` не валидирует
   схему Gson (переживёт смену схемы только через `runCatching` — риск принят ранее).

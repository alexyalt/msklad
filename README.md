# msklad

Android-приложение (Kotlin) для наполнения готового документа «Перемещение» в МойСклад: сканирование или ручной ввод кодов товаров, добавление позиций в документ и показ остатков на складе-источнике и складе-получателе.

Техническое задание: `docs/TZ.md`. Правила для агента: `AGENTS.md`. Журнал работ: `WORKBOOK.md`.

## Как пользоваться

1. Создайте документ «Перемещение» в веб-интерфейсе МойСклад (с указанием складов).
2. В приложении на экране настроек введите логин, пароль и номер или ID (UUID) перемещения, нажмите «Начать».
3. На главном экране сканируйте штрихкод камерой или введите код вручную, при необходимости укажите количество и нажмите «Отправить».
4. Зелёная зона результата и короткий звук — успех, красная и долгий низкий звук — ошибка.

## Внутренние штрихкоды

В настройках есть переключатель «Только внутренние штрихкоды»: при включении камера принимает лишь коды,
начинающиеся с `2` (этикетки, напечатанные из МойСклад), а штрихкоды производителей (EAN-13) игнорируются
с сообщением. Ручной ввод кода или артикула фильтром не затрагивается.

## Офлайн-режим

1. На стартовом экране задайте документы перемещения, оприходования и списания (последние два — по необходимости)
   и нажмите «Офлайн Синхронизация»: приложение скачает остатки исходного и целевого склада и позиции документов
   корректировки. Под кнопкой появятся две строки «склад — кол-во наименований — количество товаров».
2. Нажмите «Начать» и включите ползунок «Офлайн» в шапке экрана сканирования — запросы на сервер не отправляются,
   всё считается по локальной копии.
3. Кнопки «пер», «опр», «спис» под полем ввода переключают документ, с которым идёт работа (по умолчанию — перемещение).
4. Когда появилась связь — нажмите кнопку с двумя стрелками: накопленные позиции уйдут в документы в порядке
   оприходование → списание → перемещение, затем остатки обновятся. При ошибке очередь сохраняется и её можно отправить снова.

## Сборка

Нужны JDK 17 и Android SDK 34.

```
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. В GitHub Actions (workflow `Android CI`) APK публикуется как артефакт `msklad-debug-apk`.

## Скачать APK

После каждого push в `main` GitHub Actions собирает приложение и публикует файл `msklad-debug.apk` в релиз `latest`: https://github.com/alexyalt/msklad/releases/tag/latest

Скачайте файл на телефон и установите, разрешив установку из неизвестных источников. APK подписан отладочным ключом, предназначен для тестирования. Файл также доступен как артефакт `msklad-debug-apk` на странице запуска Actions (хранится 14 дней).
